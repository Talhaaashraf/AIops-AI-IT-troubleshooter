    Fleet · installed programs

    Software

    Everything installed on a device, with available updates. Updates use winget (Windows) or apt/dnf (Linux); uninstall runs the program's own silent uninstaller. Remove completely also finds what the program left behind and moves the items you choose to a quarantine you can restore for 7 days.

    ProgramVersionPublisherInstalledSizeActions
    Pick a device and click Scan now.

    Fleet · Microsoft products

    Microsoft Removal

    Every Microsoft product on a device: Office / Microsoft 365, Store apps and other Microsoft programs. Remove completely clears Office's registry keys, service and tasks too — using Microsoft's own scrubber when it is on the device, otherwise Microsoft's documented manual cleanup. Keys and folders are backed up first, so you can restore for 7 days from the Software tab's Quarantine. Nothing runs until you approve it.

    Fleet · one-line enrollment

    Add an agent

    Run one command on any Windows, Linux or macOS machine. It installs the AIops agent as a background service, connects it to this server, and lets the AI diagnose and fix it remotely.

    1

    Server address

    The address the remote device uses to reach this server.

    This address only works on this computer. To add other devices, enter this machine's LAN IP, e.g. http://192.168.1.20. Installing the agent on this same laptop works as is.

    2

    Enrollment token

    Created automatically when this page opens: single use, valid for 24 hours. A new one is made after each device connects.
