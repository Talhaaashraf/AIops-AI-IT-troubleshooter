    Fleet · one-line enrollment

    Add an agent

    Run one command on any Windows, Linux or macOS machine. It installs the AIops agent as a background service, connects it to this server, and lets the AI diagnose and fix it remotely.

    1

    Server address

    The address the remote device uses to reach this server.

    This address only works on this computer. To add other devices, enter this machine's LAN IP, e.g. http://192.168.1.20:8000. Installing the agent on this same laptop works as is.

    2

    Enrollment token

    A one-time token, valid for 24 hours, that lets one device register.

    3

    Run on the device

    Generate a token first.

    Waiting for the device to connect...

    Uninstall command / manual install

    Uninstall:

    Manual: copy the agent/ folder to the device, create agent_config.json from agent_config.example.json, then run pip install -r agent_requirements.txt && python monitor_agent.py.
