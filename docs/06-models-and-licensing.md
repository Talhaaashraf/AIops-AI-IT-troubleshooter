# Model folder and licensing

## Folder layout

```text
models/
  migrate_model.py      copies an installed Ollama model into a folder named after it
  qwen3-8b/             base model (migrated, optional)
    model.gguf          1.93 GB of weights (git-ignored)
    Modelfile           FROM ./model.gguf + the original chat template and system prompt
    LICENSE             the model's license (required for redistribution)
    model.json          name, size, sha256
  sentinel-tech/        self-improving model (generated by the app)
    Modelfile           FROM qwen3:8b + learned lessons + examples
    knowledge.json      lessons and stats
    training_data.jsonl fine-tuning data (git-ignored; it contains ticket content)
    version.json        build number and time
```

To migrate another model, run `python models/migrate_model.py <model>`. To recreate a migrated model on any machine, run `ollama create qwen3:8b -f models/qwen3-8b/Modelfile`.

## ⚠️ Licensing

| Model | License | Commercial use |
| --- | --- | --- |
| `qwen3:8b` (current default) | Apache 2.0 | Yes |
| `qwen2.5:3b` (previous default) | **Qwen RESEARCH License** | **No.** Non-commercial or research use only, unless you get a license from Alibaba Cloud. |
| `qwen2.5:7b` | Apache 2.0 | Yes |
| `llama3.2:3b` | Llama 3.2 Community License | Yes, with conditions (attribution, acceptable-use policy) |

The default is Apache 2.0, so AIops can be used inside a company or sold. If you switch back to `qwen2.5:3b` for speed, that use is no longer allowed. After changing the base model, rebuild `sentinel-tech` on top of it.

`qwen3:8b` was picked over the newer `qwen3.5:9b` because the 9B download (6.6 GB, with vision weights the app does not use) does not fit a laptop's 7.6 GB Docker VM alongside its context cache.

The Qwen license also requires the notice "Built with Qwen" on derived models. The `sentinel-tech` Modelfile includes it.
