# Model folder and licensing

## Folder layout

```text
models/
  migrate_model.py      copies an installed Ollama model into a folder named after it (offline installs)
  <name>/               a migrated base model, e.g. qwen3-8b/ (optional)
    model.gguf          the weights (git-ignored)
    Modelfile           FROM ./model.gguf + the original chat template and system prompt
    LICENSE             the model's license (required for redistribution)
    model.json          name, size, sha256
  aiops-brain/          AIops' own model, generated by the app (git-ignored; see 05-self-improving-model.md)
    Modelfile           FROM <base model> + principles + learned lessons + examples
    knowledge.json      lessons and stats
    training_data.jsonl fine-tuning data (lessons and this file contain ticket content)
    version.json        build number, base model and when it was built
  sentinel-tech/        from an earlier version, no longer used (git-ignored)
```

Without a migrated folder, `model-init` downloads the base model with `ollama pull`. For an install without internet:

1. On a machine that has the model, run `python models/migrate_model.py <model>`.
2. Copy the folder to the new machine.
3. `model-init` creates the model from it. You can also do it by hand: `ollama create qwen3:8b -f models/qwen3-8b/Modelfile`.

## ⚠️ Licensing

| Model | License | Commercial use |
| --- | --- | --- |
| `qwen3:8b` (default) | Apache 2.0 | Yes |
| `qwen3:4b` (for laptops with less free RAM) | Apache 2.0 | Yes |
| `qwen2.5:3b` (previous default) | **Qwen RESEARCH License** | **No.** Non-commercial or research use only, unless you get a license from Alibaba Cloud. |

The default models are Apache 2.0, so AIops can be used inside a company or sold. If you switch to `qwen2.5:3b` for speed, that use is no longer allowed. The model switcher shows each model's license, and `aiops-brain` is rebuilt automatically on top of whichever base model you pick.

`qwen3:8b` was picked over the newer `qwen3.5:9b` because the 9B download (6.6 GB, with vision weights the app does not use) does not fit a laptop's 7.6 GB Docker VM alongside its context cache.

The Qwen license also requires the notice "Built with Qwen" on derived models. The `aiops-brain` Modelfile includes it.
