# Model folder and licensing

## Folder layout

```text
models/
  migrate_model.py      copies an installed Ollama model into a folder named after it (offline installs)
  <name>/               a migrated base model, e.g. qwen3-8b/ (optional)
    model.gguf          the weights (git-ignored)
    Modelfile           FROM ./model.gguf + the original chat template and system prompt
    LICENSE             the model's license (required for redistribution)
    model.json          name, size, sha256
  aiops-brain/          AIops' own model, generated by the app (git-ignored; see 05-self-improving-model.md)
    Modelfile           FROM <base model> + troubleshooting principles
    knowledge.json      exported lesson and case statistics; not globally injected into prompts
    training_data.jsonl fine-tuning data (lessons and this file contain ticket content)
    version.json        build number, base model and when it was built
  sentinel-tech/        from an earlier version, no longer used (git-ignored)
```

Without a migrated folder, `model-init` downloads the base model with `ollama pull`. For an install without internet:

1. On a machine that has the model, run `python models/migrate_model.py <model>`.
2. Copy the folder to the new machine.
3. `model-init` creates the model from it. You can also do it by hand: `ollama create qwen3:8b -f models/qwen3-8b/Modelfile`.

## ⚠️ Licensing

| Model | License | Commercial use |
| --- | --- | --- |
| `qwen3:4b` (application default) | Apache 2.0 | Yes |
| `qwen3:8b` (optional higher-memory model) | Apache 2.0 | Yes |
| `qwen2.5:3b` (legacy option) | **Qwen RESEARCH License** | **No.** Non-commercial or research use only, unless you get a license from Alibaba Cloud. |

The current application default is `qwen3:4b`; `qwen3:8b` is an optional model for systems with enough free memory. Both are listed as Apache 2.0. If you select `qwen2.5:3b`, its research license does not permit commercial use unless you obtain a separate license. The model switcher shows each model's license, and `aiops-brain` is rebuilt automatically on top of whichever base model you pick.

Ticket-specific lessons and examples are not embedded globally in the `aiops-brain` Modelfile. Eligible past cases are retrieved for an individual diagnosis; the exported training data is for possible future fine-tuning.

The applicable Qwen license may require notices for derived models. Check the license shipped with the exact model before redistribution; do not assume the same terms apply to every model in the catalog.
